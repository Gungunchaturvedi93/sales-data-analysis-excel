# 📊 Sales Data Analysis Dashboard (Excel)

## 📌 Project Overview
This project is an interactive sales dashboard built using Microsoft Excel to analyze sales performance.

## 🔧 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## 📈 Key Features
- KPI metrics (Sales, Profit, Discount)
- Interactive dashboard with filters
- Region, category, and segment analysis
- Executive insights and recommendations

## 💡 Insights
- Technology category has highest sales
- West region gives highest profit
- Consumer segment contributes most sales
- High discounts reduce profitability
